# Store Release & Listing Checklist

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis.

## Technisch

- [ ] Version / Build-Nummer konsistent
- [ ] Target-SDK / Min-SDK / Paketformat geprüft
- [ ] Permissions/Privacy-Texte vollständig
- [ ] Signaturkonfiguration vorhanden und autorisiert
- [ ] Release-Build erzeugt (Pfad dokumentiert)
- [ ] Install + Kernflows getestet

## Listing Copy

- [ ] Kurzbeschreibung (Längenlimit)
- [ ] Langbeschreibung (nur echte Features)
- [ ] Versionshinweise aktuell
- [ ] Keywords / Kategorie angemessen
- [ ] Keine irreführenden Claims

## Assets

- [ ] App-Icon Spec erfüllt
- [ ] Screenshots je erforderlichem Gerät
- [ ] Feature-/Promo-Grafik falls nötig
- [ ] Branding konsistent

## Lokalisierung

- [ ] Pflichtsprachen vollständig
- [ ] Übersetzungsqualität Stichprobe
- [ ] Längenlimits je Locale

## Publish Gate

- [ ] Explizite Nutzerfreigabe für Live-Publish
- [ ] Track (Internal/Closed/Open/Prod) dokumentiert
- [ ] Rollback-Pfad bekannt
