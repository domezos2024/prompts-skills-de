## Orchestrierungsregeln

- [ ] Jeder aktivierte Eintrag hat Skill-Pfad oder expliziten „Prompt-only“-Hinweis
- [ ] Schreibende Skills sequentiell ordnen bei Dateiüberlappung
- [ ] Freigabe-Gates (Store publish, Live pay, git push) separat markieren
- [ ] Nicht vorhandene Skills nicht fingieren – Gap dokumentieren
