# Onboarding & Retention Checklist

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis.

## First-Value Path

- [ ] Erste Kernaktion definiert
- [ ] Schritte vom Öffnen bis Erfolg gezählt
- [ ] Drop-off-Punkte priorisiert (P0–P3)
- [ ] Unnötige Pflichtfelder entfernt/optionalisiert

## Guidance

- [ ] Erklärungen klar und kurz
- [ ] Kontextuelle Hilfe statt langer Tours
- [ ] Empty States mit nächstem Schritt
- [ ] Guided Setup optional / überspringbar

## Feedback

- [ ] Fehlermeldungen verständlich + nächster Schritt
- [ ] Erfolgsbestätigungen nach relevanten Aktionen
- [ ] Loading/Progress erkennbar

## Retention (ethisch)

- [ ] Keine Dark Patterns
- [ ] Keine erzwungenen Bewertungen
- [ ] Keine manipulativen Pop-up-Schleifen
- [ ] Wiedereinstieg ohne Reibung

## Messung

- [ ] Hypothesen dokumentiert
- [ ] Kennzahlen datensparsam und zweckgebunden
- [ ] Erstanwender-Szenarien getestet
