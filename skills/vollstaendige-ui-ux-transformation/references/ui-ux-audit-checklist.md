# UI/UX Audit Checklist

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis (Datei/Screenshot/Notiz).

## Layout & Hierarchie

- [ ] Primäre Aktion pro View eindeutig
- [ ] Visuelle Hierarchie (H1/H2/Body) klar
- [ ] Abstände konsistent (Spacing-Skala)
- [ ] Keine überladenen Regionen ohne Gruppierung
- [ ] Alignment-Raster eingehalten

## Typografie & Farbe

- [ ] Max. 2–3 Schriftrollen/Weights sinnvoll
- [ ] Lesbare Größen (≥ 14px Body typisch, Kontext beachten)
- [ ] Kontrast Text/Hintergrund ausreichend (Ziel WCAG AA)
- [ ] Semantische Farben (danger/success/info) konsistent

## Responsiveness

- [ ] Mobile Breakpoint ohne horizontalen Overflow
- [ ] Touch-Targets ausreichend groß
- [ ] Navigation auf schmalen Viewports bedienbar

## Interaktion & Feedback

- [ ] Focus sichtbar
- [ ] Loading-Zustände vorhanden
- [ ] Fehler verständlich + nächster Schritt
- [ ] Erfolg bestätigt wo relevant
- [ ] Empty States hilfreich

## Accessibility

- [ ] Semantische Elemente / Rollen
- [ ] Alt-Texte / aria-labels wo nötig
- [ ] Tastaturbedienung kritischer Flows
- [ ] Keine Information nur über Farbe

## Konsistenz

- [ ] Buttons/Inputs einheitlich
- [ ] Icon-Stil einheitlich
- [ ] Dialoge/Modals einheitlich
