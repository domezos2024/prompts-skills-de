# WCAG Conformance Checklist (praktisch)

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis. Scores allein reichen nicht.

## Perceivable

- [ ] Textalternativen für Nicht-Text-Inhalte
- [ ] Kontrast Text/UI ausreichend (Ziel AA wo gefordert)
- [ ] Inhalt ohne reine Farbcodierung verständlich
- [ ] Zoom/Reflow ohne kritischen Verlust

## Operable

- [ ] Alle kritischen Funktionen per Tastatur
- [ ] Sichtbarer Fokus
- [ ] Keine Tastaturfalle
- [ ] Sinnvolle Fokusreihenfolge
- [ ] Skip-Link / Landmarks wo sinnvoll

## Understandable

- [ ] Sprache im HTML gesetzt
- [ ] Labels und Instruktionen klar
- [ ] Fehler erkannt, beschrieben, korrigierbar
- [ ] Konsistente Navigation

## Robust

- [ ] Valides/semantisches Markup für Controls
- [ ] Name/Role/Value für Custom Widgets
- [ ] ARIA nur ergänzend, nicht widersprüchlich
- [ ] Dynamische Updates (Live-Regions) geprüft
