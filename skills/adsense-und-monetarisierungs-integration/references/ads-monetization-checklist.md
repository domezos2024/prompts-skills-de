# Ads & Monetization Checklist

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis.

## Inventory

- [ ] Bestehende Ad-Tags/Slot-IDs aus Projektquellen erfasst
- [ ] Fehlende IDs als Blocker markiert (nicht erfunden)
- [ ] Layout-Zonen und kritische Controls kartiert
- [ ] CMP/Consent-Tool und Regionen dokumentiert

## Policy & Consent

- [ ] Einwilligung vor nicht-essentiellen Ad-Scripts (wo erforderlich)
- [ ] Widerrufspfad getestet
- [ ] Keine irreführende Platzierung nahe Primary Actions
- [ ] Publisher-Richtlinien-Risiken notiert

## Technical

- [ ] Slot-Container technisch korrekt
- [ ] CSP-Kompatibilität geprüft/dokumentiert
- [ ] Lazy/Consent-gated Loading wo sinnvoll
- [ ] Responsive Breakpoints ohne Überlagerung
- [ ] CLS-Smoke durchgeführt

## Go-live

- [ ] Explizite Nutzerfreigabe für Prod
- [ ] Live-Status nur mit Bestätigung behauptet
