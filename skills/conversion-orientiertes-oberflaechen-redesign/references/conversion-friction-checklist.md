# Conversion-Friction- & Ethik-Checkliste

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis. Übertrifft Prompt: Funnel-Stufen, Friction-Scoring, Dark-Pattern-Gate und Messplan-Integrität.

## A. Zielklarheit

- [ ] Primäre Nutzeraktion in einem Satz formuliert
- [ ] Zielgruppe und Einstiegskontext dokumentiert
- [ ] Seitenzweck (Landing/Signup/Download/Checkout) eindeutig
- [ ] Ein visueller Primär-CTA; Sekundär klar untergeordnet

## B. Funnel-Stufen (Ist → Soll)

| Stufe | Ist-Hürde | Severity (P0–P3) | Geplante Änderung | Evidence |
|-------|-----------|------------------|-------------------|----------|
| Aufmerksamkeit (Hero/Headline) | | | | |
| Verständnis (Nutzen/Differenzierung) | | | | |
| Vertrauen (Social Proof, Sicherheit, Klarheit) | | | | |
| Aktion (CTA) | | | | |
| Formular / Checkout-Schritte | | | | |
| Fehler / Abbruch-Recovery | | | | |
| Erfolg / Next Step | | | | |

## C. Content & Hierarchie

- [ ] Headline vermittelt Nutzen, nicht nur Feature-Jargon
- [ ] Subcopy stützt einen Einwand oder konkreten Outcome
- [ ] CTA-Label beschreibt Ergebnis („Konto erstellen“) statt vage („Submit“)
- [ ] Ablenkende Module unterhalb der Faltkante priorisiert oder entfernt
- [ ] Trust-Elemente spezifisch und glaubwürdig (keine Fake-Zähler)

## D. Formular-Friction

- [ ] Minimale Felder für den Schritt; optionale klar markiert
- [ ] Inline-Validierung verständlich; Fehler nennen nächsten Schritt
- [ ] Passwort/Payment-Hilfen ohne Irreführung
- [ ] Mobile Tastatur/Viewport: Submit erreichbar
- [ ] Rechtstexte/Opt-ins klar, nicht vorausgewählt wider Recht/Ethik

## E. Dark-Pattern-Gate (MUST Fail → blockiert Delivery)

- [ ] Keine versteckten Kosten / nachträgliche Pflichtupsells ohne Klarheit
- [ ] Keine Fake-Knappheit oder erfundene Social Proofs
- [ ] Kein Confirmshaming als einzige Ablehnoption
- [ ] Keine irreführende UI-Hierarchie (Opt-out optisch als Opt-in)
- [ ] Keine vorgetäuschten Systemmeldungen

## F. Responsiveness & Flow-QA

- [ ] Mobile und Desktop Kernflow getestet
- [ ] Loading/Error/Success vorhanden
- [ ] Vorher/Nachher-Screenshots abgelegt
