# Fair Monetization Checklist

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis.

## Strategie

- [ ] Produktwert und laufende Kosten erfasst
- [ ] Zielgruppe und Zahlungsbereitschaft begründet
- [ ] Modelle verglichen (Spende / Einmal / Premium)
- [ ] Anbietergebühren und technische Limits dokumentiert

## Transparenz & UX

- [ ] Preise und Bedingungen klar sichtbar
- [ ] Keine versteckten Gebühren / Dark Patterns
- [ ] Support-Seite im Designsystem
- [ ] Erfolg/Fehler/Cancel verständlich

## Integration

- [ ] Nur autorisierte Integration
- [ ] Test-/Sandbox-Modus genutzt
- [ ] Return-to-App geprüft
- [ ] Webhooks (falls vorhanden) geprüft
- [ ] Secrets nicht im Repo

## Go-Live Gate

- [ ] Explizite Freigabe für Live-Zahlungen
- [ ] Ops-/Privacy-Doku vorhanden
- [ ] Offene rechtliche Punkte benannt (kein Rechtsrat vortäuschen)
