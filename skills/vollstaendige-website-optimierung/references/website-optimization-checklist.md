# Website Optimization Checklist

Jedes Item: `Pass` | `Fail` | `N/A` + Beweis.

## Inventar

- [ ] Seitenliste / Templates erfasst
- [ ] Kritische User-Journeys markiert
- [ ] Asset-Typen (img/font/css/js) inventarisiert
- [ ] Interne Verlinkung grob kartiert

## Performance

- [ ] Bilder optimiert / moderne Formate wo sinnvoll
- [ ] Fonts reduziert / korrekt geladen
- [ ] CSS/JS Payload und Blocking geprüft
- [ ] Caching/Headers sinnvoll
- [ ] CLS/LCP-Risiken adressiert

## Technical SEO

- [ ] Titles/Descriptions vorhanden und eindeutig
- [ ] Canonicals korrekt
- [ ] Heading-Hierarchie sinnvoll
- [ ] Structured Data nur bei echten Inhalten
- [ ] Sitemap + robots.txt konsistent
- [ ] Redirects/404 geprüft

## Accessibility & UX

- [ ] Kontrast / Fokus / Semantik Spot-Check
- [ ] Tastaturpfade kritischer Flows
- [ ] Mobile Layout ohne Overflow
